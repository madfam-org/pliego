# Code of Conduct

> Boundary checkpoint (2026-10-10): public policy.

Pliego adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be kind, assume good faith, give and take feedback gracefully,
and never harass, demean or publish anyone's private information.

**Scope.** This repository — issues, pull requests, discussions, commit messages and review
comments — and any space where someone represents the project.

**Heritage and communities.** Paper traditions belong to living communities. Discussing, citing
and crediting them is welcome; mocking them, or presenting a community's tradition as someone's
personal invention, is not.

**Reporting.** Use GitHub's private vulnerability reporting for this repository (Security tab) and
mark the report "code of conduct", or contact the maintainers through the profile listed in
`.github/CODEOWNERS`. Reports are handled confidentially by the maintainer of record, Innovaciones
MADFAM S.A.S. de C.V. Enforcement follows the Covenant's guidelines: correction, warning,
temporary ban, permanent ban.
