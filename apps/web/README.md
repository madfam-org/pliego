# apps/web — Pliego landing and studio

Static HTML + CSS + vanilla ES modules. No bundler, no framework, no CDN, no third-party code, no
install step. Everything runs under a strict CSP (`script-src 'self'; style-src 'self';
default-src 'none'`): no inline scripts or handlers, no `style=` attributes, no external requests.

| Path | What |
|---|---|
| `index.html`, `assets/` | Landing (en/es/fr/pt), CSS-only paper-fold hero, OG/hreflang/JSON-LD, `<!-- ecosystem-banner slot -->` |
| (none) | `llms.txt`/`llms-full.txt` live at the repo root (single source; the dev server and the API both serve them); `robots.txt` and `sitemap.xml` are generated per host by the API |
| `shared/` | i18n runtime (`data-i18n`, `data-i18n-attr`, `pliego:lang` event), guarded storage, pre-paint `lang-boot.js` |
| `studio/` | Studio: catalog, parameters, controls from `pliego:controls`, fold-program scrubber, 3-D view, SVG crease-pattern view, exports, share URL, status bar |
| `studio/src/render/` | Self-contained renderers: WebGL2 (two-sided paper, grain, PCF shadow map, ground, crease overlay, printed faces) and a Canvas 2D 3-D fallback; shared orbit/pan/zoom/grab input |
| `studio/src/render/printed.js` | Printed faces, DOM-free: per sheet side, `front.art`/`back.art`, then `pliego:artwork` (placed, rotated, clipped to its dieline panel or bleed), then `pliego:annotations` (front only), composited into the WebGL art texture array (square layers ≤ 2048 px, ≤ 64 MB in all, mipmapped; the back is drawn mirrored so it reads right from behind). Art URL policy: images only (`new Image()`, never fetched or inserted), same-origin relative paths, `data:image/svg+xml` and `data:image/png;base64`; anything else is skipped with one warning. The Canvas 2D fallback draws flat paper colours (no art or artwork) and pins annotation texts on front-facing paper |
| `studio/src/engine-stub.js` | Kinematic test double with the engine API (`docs/strategy/engine.md` §5); used only when `/engine/index.js` is absent. Honours a sheet's `presentation` (spec §5.16: the face held still, an end transform blended in over the program) and lifts the posed scene so no paper passes below the table (`y = 0`; `new World(doc, {ground: false})` turns that off) |
| `studio/demo/` | Demo sheet documents + `catalog.json`, generated by `scripts/make-demos.mjs` |
| `dev-server.mjs` | Local static server (Node built-ins), strict CSP header, `/engine/` mount, `/api/*` → 404 |

## Run

```bash
node apps/web/dev-server.mjs --port 8090                      # http://127.0.0.1:8090/ and /studio/
node apps/web/dev-server.mjs --engine /path/to/packages/engine/src   # or PLIEGO_ENGINE_DIR=…
```

Studio URL switches (testing): `?renderer=canvas2d` forces the Canvas 2D renderer,
`?engine=stub` forces the stub, `?lang=es` picks a language. Share links carry the object in
`?slug=` and parameters in the hash (`#width=200&_view=2d`).

## Test

```bash
node --test apps/web/test/                       # i18n parity, CSP lint, math, printed faces, demo docs, engine contract
node apps/web/scripts/make-demos.mjs --check      # demo documents match their generator
node apps/web/scripts/make-og.mjs --check         # OG image matches its generator (~10 s)
```

To run the engine contract against the real engine without committing it:

```bash
mkdir -p apps/web/.engine-tmp && git archive origin/lane/engine packages/engine/src | tar -x -C apps/web/.engine-tmp
node --test apps/web/test/                       # picks up apps/web/.engine-tmp/packages/engine/src
```

## API seams (served by `apps/api` when it runs)

`GET /api/v1/catalog` (falls back to `studio/demo/catalog.json`), `POST /api/v1/documents
{slug, params}` (parameter changes), `POST /api/v1/exports {slug, params, format}` (cut/score/fold
files). Without the API, parameters and exports are visibly disabled; the crease-pattern SVG export
works offline.

Busy answers: a render worker that is already rendering answers `503`, the rate limiter `429`, both
with `Retry-After`. The studio waits and retries a render request up to 3 times (the n-th wait is
n × Retry-After; a Retry-After above 5 s or a busy answer without one is shown, not retried), and
only the latest document request (a parameter change, a mode change or an object pick) may replace
the document on screen (`studio/src/data.js`: `postRender`, `latestOnly`).
