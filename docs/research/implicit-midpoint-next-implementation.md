## Minimal contract and equations

Add opt-in `timeIntegrator: 'implicit-midpoint'`, admitted only with the current `reference-displacement` / UV-reference / double-double / membrane-inertia-increment research configuration. Omission remains backward Euler with its existing arithmetic, metadata and historical snapshot shapes. Freeze a separate versioned integrator identity; do not alter the meaning of the existing reference-coordinate identity. Accept only the already admitted all-free, finite exact-Y=0, zero-external-work, undamped domain. No contact, grab, crease/join, gravity, moving constraints, nonzero hinge work or paper-stock validation is introduced.

For physical step h, previous endpoint u0,v0 and fixed native M, solve one stage:

    target = u0 + (h/2)*v0
    grad U(um) + C4*(um-target) = 0
    delta = um-u0
    u1 = u0 + 2*delta
    v1 = (4/h)*delta - v0

Specify these exact binary64 operation associations in the new identity, not just their real equations. Suggested native coefficient: `halfH = 0.5*h`, `inverseHalfSquare = 1/(halfH*halfH)`, `C4[i] = mass[i]*inverseHalfSquare`; require all intermediates finite and positive. Do not silently replace it with `4*(mass[i]*(1/(h*h)))`. Use left-associated `u0 + halfH*v0`, then the centered endpoint operations above, with no re-projection into authority. Store raw C4 words. All projectors remain `round(X0+u)` and all initial signed words retain the current exact-conversion/refusal rules.

`previousPoseStart=false` initializes um to this half-step predictor; true initializes um to u0. Both receive exactly I declared Newton iterations, no extra solve or hidden accuracy iterations. This is a different target from the existing full-step predictor. Endpoint velocity is v1; `(u1-u0)/h` is midpoint velocity, not endpoint velocity. Their binary64 discrepancy from `(v0+v1)/2` is an explicit rounding diagnostic.

## Time, failure and public evidence

A public `step(h)` advances one physical endpoint: one frame and one substep, physical time plus h, and one stage solve. Never call public `step(h/2)` twice. `World.step`290–302 already increments frames before the substep, and sleeping advances time without substeps; a wrapper cannot infer successful stages from time alone. Continue strict runner receipts: initial, sleeping, error, incomplete stage, failed endpoint metric/projection, or no actual execution receipt gives **null target/convergence certificates**, with actual raw words/status retained. A valid stage does not rescue an invalid endpoint.

Compute endpoint candidates in owner buffers and validate finite planar/projected metric before committing u1/x/v1; failed native search raw state and failure phase remain visible. This is not a promise that the entire existing World.step is transactional: its frames/accumulator may already have changed. Such a failed observation must be invalid, rather than repaired to appear like a successful boundary. Freeze this failure policy before captures. Retain existing sleep policy and refuse asleep runs rather than inventing an unreported sleep override.

Add `midpointState` to the opt-in authoritative snapshot. For `authoritativeResiduals(tau)` dispatch a **new named schema** with `certificateLocation:'midpoint-stage'`, stage time `timeStart+halfH`, projected stage/target, authoritative and public stage elastic/inertia/full residuals, and independent flags. Endpoint force is elastic-only diagnostic (or separately named hypothetical BE residual); it cannot be labeled the midpoint convergence gate. Both real stage residual gates keep the frozen original F0/tau. Evaluate observations on scratch clones as today. Stage target/result receipts bind endpoint recurrence and previous raw words; all finite, signed-zero and NaN raw-LE preservation rules remain.

## Independent truth and acceptance gates

1. **State/force**: raw LE/SHA bindings include stage/endpoint/previous/targets/native C4 and all execution policy words. Independent validator redoes every native operation association and checks stage force vectors, original tau classifications, endpoint update and actual clock/counters. Constructor/failed roles are explicitly skipped as force targets, not converted to passes. A producer green flag alone is insufficient.
2. **Independent linear discrete truth**: independently assemble represented rest K and positive diagonal captured C4. Propagate the complete actual u0/v0 using `(K+C4) um = C4*(u0+halfH*v0)` and the declared endpoint equations, including translations/null modes and leakage. This is selected-native-C4 linear midpoint truth, not a scalar ideal-mode injection. Separately compute real `4M/h²` discrete truth and continuous physical linear truth; report selected material/rounding differences. Native C4 implies effective linear mass h²*C4/4, so an exact-real quadratic-energy claim about that mass is distinct from physical M.
3. **Independent nonlinear point truth**: current `membrane-state-precision.py:assemble`132 and its direct tensor/Piola material evaluation can be shared as pure math, but its schema/identity and inertia checks are BE-specific. Add a new stage adapter with explicit LE C4/target, authoritative um and projected stage/target, checking both residuals with unchanged force gates and original material alternatives. Evaluate endpoint elastic/kinetic energy separately. Sampled point truth does not certify the entire nonlinear trajectory; independent high-precision nonlinear time solutions require a separately predeclared scope.
4. **Energy/work**: midpoint is not exact quartic-StVK energy conservation. For exact real physical-M midpoint equations with stage residual r, `ΔE = ΔU - gradU(um)·d + r·d`; at exact solve the quartic work defect is `D³U(um)[d,d,d]/24`, d=u1-u0. Native-C4 vs4M/h² contributes a separate coefficient-work defect, and rounded predictor/stage/endpoint/velocity recurrences contribute further measured identity defects. Use exact-rational represented-word point calculations to close that work balance and bound solve work; do not explain all energy drift as truncation. Retain physical endpoint energy maxima, drift/sign/oscillation and leakage throughout the trajectory, not just terminal energy or stage objective decrease.
5. **Separate decisions**: original two force gates; linear selected-integrator error; continuous amplitude/velocity/state/phase/energy error; I4→16 solve-isolation; adjacent-level temporal convergence at common physical times; and replay/instrumentation parity. Preserve existing numeric diagnostic limits (.001 discrete field/velocity, .005 discrete energy; .01 continuous field/velocity, .05 energy, .01 phase cycles;1e-4 solve isolation) with a clearly declared midpoint reference. Add an energy-work closure threshold justified by independent numerical error **before** capture; until declared it is a measured unresolved gate. An analytic second-order modal estimate is neither a World result nor a blanket nonlinear-stability guarantee.

## Meaningful implementation closure tests (future, not run here)

- Default omitted/explicit BE remains native snapshot/trajectory identical. Wrong integrator combinations and each omitted-physics drift fail before controlled writes; finite/overflow h/C4 and native signed-zero initial refusals remain.
- Nonzero initial v, both starts and at least two consecutive steps verify each native stage predictor/point/C4, endpoint u/v recurrence, views, physical time and counters. Constant free translation and a represented linear oscillator distinguish endpoint v from midpoint velocity; a zero-v-only test would miss this bug.
- Direct and stale-factor/PCG paths use the same stage coefficient and force; rejected/precision-limited trials restore the stage, not endpoint authority. Instrumented and plain execution are byte equal; callbacks see copied correct stage buffers and cannot snapshot midstep.
- Snapshot after a completed step, restore and advance yields exact stage/endpoint/search/factor replay; corrupt factor stage/C4, cross-integrator identity, forged previous state/counters/green flags and failed/sleep receipts reject without false force certification.
- Independent full-vector linear stage solve agrees with implementation within predeclared error; real-M amplitude/phase convergence and quartic work/residual identities are separate checks. No test claims contact/material/booklet/device validation.
